Buat section Galeri Kegiatan di homepage menggunakan Tailwind CSS dengan ketentuan:

- Layout grid:
    - 1 kolom di mobile
    - 2 kolom di tablet (sm:grid-cols-2)
    - 4 kolom di desktop (lg:grid-cols-4)

- Gunakan card style seperti foto polaroid:
    - Background putih
    - Shadow
    - Padding
    - Caption di bawah gambar

- Batasi ukuran gambar:
    - Tinggi tetap 250px
    - object-cover
    - Lebar penuh (w-full)
    - Jangan sampai menutup seluruh halaman

- Tambahkan hover effect ringan:
    - hover:-translate-y-2
    - transition

CONTOH CODE (TAILWIND)
