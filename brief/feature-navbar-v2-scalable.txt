============================================================
ROUTING PRINCIPLE

IMPORTANT:
Grouping hanya di level UI.
Routing tetap flat.

Contoh:
- /renungan
- /pengumuman
- /donasi

Tidak membuat nested route seperti:
- /rohani/renungan

============================================================
RESPONSIVE BEHAVIOR

DESKTOP:
- Dropdown muncul saat hover
- Smooth transition
- Donasi tampil sebagai button berbeda warna
- Dropdown memiliki shadow dan rounded corner

MOBILE:
- Hamburger menu
- Dropdown expand on click
- Nested links indented

============================================================
ACTIVE LINK LOGIC

Gunakan:
usePathname() dari next/navigation

Logic:
- Parent menu aktif jika salah satu child route aktif
- Child link aktif diberi highlight berbeda

Contoh:
Jika path = /renungan
→ Rohani parent highlighted
→ Renungan child highlighted

============================================================
COMPONENT STRUCTURE

Buat atau update:

components/layout/Navbar.tsx

Optional split:
components/layout/NavItem.tsx
components/layout/NavDropdown.tsx
components/layout/MobileMenu.tsx

Navbar di-load dari:
app/layout.tsx
