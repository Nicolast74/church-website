PROJECT NAME:
Church Website – St. Agustinus, St. Yohanes, & Taman Doa Bintang Samudra

PROJECT TYPE:
Church Website MVP (Public-first, scalable to Admin CRUD)

GOAL:
Build a simple, informative, and maintainable church website.
Phase 0 focuses on public-facing pages only.
Phase 1 adds admin login and CRUD features.
Design prioritizes clarity, accessibility, and long-term maintainability.

TARGET USERS:
- Public / Jemaat Gereja
- Internal Church Administrators (Admin only)

NON-GOALS:
- No public user accounts
- No public comments
- No payment system
- No livestream system (YouTube embed/link only if needed later)

--------------------------------------------------
TECH STACK
--------------------------------------------------

Frontend:
- Next.js (App Router)
- Tailwind CSS

Backend (Phase 1):
- Supabase
  - Auth (Admin only)
  - Database (PostgreSQL)
  - Storage (Gallery images)

Hosting:
- Vercel (Frontend)
- Supabase (Backend)

Design Approach:
- No Figma
- Text-based layout (TUI style)
- Component-first development

--------------------------------------------------
PHASE 0 – MVP (PUBLIC WEBSITE)
--------------------------------------------------

PAGES:

1. HOME  (/)
- Hero section (church tagline / bible verse)
- Quick access to upcoming schedules
- Latest activities / announcements
- Gallery preview
- Footer with contact info

2. JADWAL IBADAH & KEGIATAN  (/jadwal)
- List of worship schedules
- List of church activities
- Filter by location
- Filter by activity type

3. BACAAN  (/bacaan)
Sub-pages:
- Bacaan Harian   -> /bacaan/harian
- Bacaan Ibadah   -> /bacaan/ibadah

Content:
- Date-based reading
- Structured reading sections (Bacaan I, Mazmur, Injil)

4. KALENDER LITURGI  (/kalender-liturgi)
- Monthly liturgical calendar
- Color-coded liturgical days
- Feast / memorial information

5. GALERI KEGIATAN  (/galeri)
- Photo gallery
- Filter by location
- Caption per photo
- No public comments

6. KONTAK & KEPENGURUSAN  (/kontak)
- Pastor information
- Secretariat contact
- Email
- Church address
