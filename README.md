# Church Website

This is a simple, informative, and maintainable church website built with Next.js and Tailwind CSS.

## Tech Stack

- [Next.js](https://nextjs.org/) (App Router)
- [Tailwind CSS](https://tailwindcss.com/)
- [TypeScript](https://www.typescriptlang.org/)

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Folder Structure

- `/app`: Contains all the routes and pages for the application.
- `/components`: Contains all the reusable components.
- `/lib`: Contains all the utility functions and libraries.
- `/public`: Contains all the static assets, such as images and fonts.
- `/styles`: Contains all the global styles and Tailwind CSS configuration.
